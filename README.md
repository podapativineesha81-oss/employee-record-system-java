# Employee Record System (Java)

A simple Java-based **Employee Record System** that allows users to manage employee information through a menu-driven console application.

## Features

- Add employee records
- View all employees
- Search employee by ID
- Update employee information
- Delete employee records
- Store employee name, department, and salary
- Simple menu-driven interface

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## Project Structure

## How to Run

Compile:

```bash
javac EmployeeRecordSystem.java
```

Run:

```bash
java EmployeeRecordSystem
```

## Sample Menu

====== Employee Record System ======

1. Add Employee

4. Update Employee
5. Delete Employee
